# Memory bank — справочник состояния проекта

Набор файлов для быстрого входа в контекст портала нотариальной конторы.
Правила разработки здесь **не** дублируются: они лежат в `clinerules/`.

| Файл | О чём |
| --- | --- |
| `projectbrief.md` | что за проект, цель, стек, запуск, где что искать |
| `productContext.md` | разделы и маршруты, что считают калькуляторы, особенности поведения |
| `techContext.md` | окружение, версии, БД, как проверять изменения |
| `systemPatterns.md` | паттерны модуля, рендеринга, клиентских скриптов, дизайна |
| `activeContext.md` | текущая задача, её проверки и открытые вопросы, состояние git |
| `progress.md` | что работает, незавершённое, хроника задач, как продолжать |

Правила ведения:

- Обновлять после завершения каждой задачи: `activeContext.md` — текущее
  состояние и открытые вопросы, `progress.md` — хроника и незавершённое,
  остальные файлы — только если изменились факты (маршруты, стек, паттерны).
- Записывать только проверенные факты со ссылкой на файл/команду; догадки
  помечать явно как открытые вопросы.
- Если код расходится с `clinerules/`, фиксировать это как открытый вопрос
  с вариантами решения, а не менять правило или код молча.
- Источник истины — код и `clinerules/`; при расхождении с этим справочником
  верить коду и поправить справочник.
