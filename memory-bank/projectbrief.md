# Портал нотариальной конторы — краткая справка

## Что это

Внутренний портал нотариальной конторы для локальной сети (до 15 сотрудников):
веб-приложение на FastAPI с серверным рендерингом Jinja2 и SQLite. Клиентского
фреймворка нет: интерактивность (калькуляторы, поиск, таблицы) — обычный
JavaScript в `app/static/js/`.

Корень проекта — корень рабочего каталога (`Portal/`). Это единственный
проект в рабочем пространстве.

## Цель

Расширяемый каркас портала: новые функции добавляются отдельными
папками-модулями в `app/modules/` без переписывания существующего кода.
Стек, структура и дизайн зафиксированы в `clinerules/`.

## Границы

В работе сейчас: вход и пользователи, калькуляторы, база заготовок.
Заявлены, но ещё не реализованы: лица/карточки, канбан, календарь
(Google Calendar), интеграции, PostgreSQL вместо SQLite, Alembic-миграции.

## Стек

- Python 3.11+ (в окружении 3.12), FastAPI 0.115, Uvicorn
- SQLAlchemy 2.0 async + aiosqlite, SQLite `portal.db` в корне
- Jinja2 3.1, pydantic 2.10 + pydantic-settings, python-multipart
- passlib + bcrypt, python-jose (JWT HS256) в httpOnly-cookie `portal_token`
- Alembic 1.14 — конфиг есть, миграции не используются (таблицы создаёт
  `Base.metadata.create_all` при старте)

## Запуск

```powershell
run.bat                     # venv, зависимости, .env, админ при первом запуске, сервер
# либо вручную
venv\Scripts\Activate.ps1
uvicorn app.main:app --host 0.0.0.0 --port 8000
python scripts/create_admin.py --name "Иванов Иван Иванович" --password "..."
```

Портал: <http://127.0.0.1:8000/auth/login>. Логин — ФИО сотрудника на русском,
пароль — bcrypt-хеш. Вход открыт всем авторизованным разделам, «Пользователи» —
только роли `admin` (в интерфейсе «Нотариус»).

## Где что искать

- `clinerules/01-carcass.md` — правила каркаса проекта: стек, структура,
  что можно и чего нельзя делать.
- `clinerules/02-calculators.md` — правила раздела «Калькуляторы» и эталонный
  код блока (образцы: ДКП обязательная форма — клиентский расчёт, госпошлина —
  серверный).
- `memory-bank/` — этот справочник: состояние, контекст, наработки.
- `README.md` — вход, роли, переменные окружения, скрипт админа.
  Часть описания (структура, «Раздел») отстаёт от кода — источником истины
  считать код и `clinerules/`.
